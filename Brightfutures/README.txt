BRIGHT FUTURES - BLACK LEARNER IMAGE UPGRADE

1. Extract this ZIP file to a folder on your computer.
2. Keep index.html, services.html, about.html, how-it-works.html, enrolment.html, style.css, script.js and the images folder together.
3. Open index.html in your browser.
4. Use the navigation menu to visit all five pages.

The images folder contains four original AI-generated educational images featuring Black children learning, reading, practising maths and receiving tutor support. The images are stored locally in this folder, so they do not depend on an external photo website.

The enquiry form is still a demonstration: it displays a confirmation message but does not email, transmit or store enquiries. Do not enter real children's personal information.
